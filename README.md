# نواقص | Nawaqes - منصة الإعلانات الذكية

منصة إعلانات ذكية متكاملة تدعم اللغة العربية، مع مساعد ذكاء اصطناعي للترويج، ونظام محفظة إلكترونية، وسوق إلكتروني.

## المميزات

- 🧠 **مساعد الذكاء الاصطناعي** - اقتراحات ترويج ذكية واستهداف تلقائي
- 💰 **محفظة إلكترونية** - شحن الرصيد ودفع تكاليف الترويج
- 🏪 **سوق إلكتروني** - نشر وإدارة الإعلانات
- 📊 **تحليلات متقدمة** - متابعة أداء الترويج والوصول
- 🌐 **دعم ثنائي اللغة** - عربي / إنجليزي
- 🌙 **وضع داكن** - دعم كامل للوضع الداكن
- 🔒 **نظام مصادقة آمن** - JWT مع تشفير متقدم
- 📸 **دعم جميع صيغ الصور والفيديو** - JPG, PNG, GIF, WebP, AVIF, HEIC, MP4, MOV, AVI, MKV والكثير

## بيانات الدخول الافتراضية (لوحة التحكم)

| الدور | البريد الإلكتروني | كلمة المرور |
|-------|-------------------|-------------|
| المدير | admin@nawaqes.com | Admin@2024 |
| المالك | owner@nawaqes.com | Owner@2024 |

## طريقة الدخول على لوحة التحكم

1. افتح الموقع في المتصفح
2. اضغط على زر **تسجيل الدخول** (أو أيقونة المستخدم)
3. أدخل البريد الإلكتروني: `admin@nawaqes.com` أو `owner@nawaqes.com`
4. أدخل كلمة المرور: `Admin@2024` أو `Owner@2024`
5. بعد تسجيل الدخول، اضغط على أيقونة **لوحة التحكم** (⚙️) في القائمة الجانبية أو العلوية
6. ستظهر لك لوحة التحكم مع جميع الأقسام: الإحصائيات، المستخدمين، المنشورات، التعليقات، الترويج، المحفظة، الإعدادات وغيرها

> ⚠️ **مهم**: غيّر كلمات المرور الافتراضية بعد أول تسجيل دخول من خلال صفحة الإعدادات!

## النشر على Hugging Face Spaces

1. أنشئ Space جديد على [huggingface.co/spaces](https://huggingface.co/new-space)
2. اختر **Docker** كـ SDK
3. ارفع جميع ملفات المشروع إلى المستودع
4. سيتم البناء تلقائياً باستخدام Dockerfile
5. الموقع سيعمل على المنفذ 7860

## النشر على GitHub

```bash
git init

git remote add origin https://github.com/safwatkhokha/nawaqes.git
```

## التشغيل المحلي

```bash
# تثبيت التبعيات
npm install

# إعداد البيئة
npm run setup

# تشغيل في وضع التطوير
npm run dev

# بناء للإنتاج
npm run build

# تشغيل نسخة الإنتاج
npm start
```
